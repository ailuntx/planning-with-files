---
description: "一目了然展示当前规划状态——阶段、进度及任何已记录的报错。"
---

读取当前项目目录下的 task_plan.md 文件，并显示简洁的状态摘要。

## 显示内容

1. **当前阶段**：从 "## Current Phase" 部分提取
2. **阶段进度**：统计各阶段及其状态（待处理/进行中/已完成）
3. **阶段列表**：显示每个阶段及其状态图标
4. **报错**：统计 "## Errors Encountered" 表格中的条目（如果存在）
5. **文件检查**：确认哪些规划文件存在

## 状态图标

- `[ ]` 或 "pending" → ⏸️
- "in_progress" → 🔄
- `[x]` 或 "complete" → ✅
- "failed" 或 "blocked" → ❌

## 输出格式

```
📋 规划状态

当前：第 {N} 阶段，共 {total} 个阶段（{percent}%）
状态：{status_icon} {status_text}

  {icon} 阶段 1：{name}
  {icon} 阶段 2：{name} ← 当前位置
  {icon} 阶段 3：{name}
  ...

文件：task_plan.md {✓|✗} | findings.md {✓|✗} | progress.md {✓|✗}
已记录报错：{count} 个
```

## 如果规划文件不存在

```
📋 未找到规划文件

请运行 /plan 以开始新的规划会话。
```

## 保持简洁

这是一个快速状态检查，而非完整报告。仅显示足够信息以回答“我当前处于什么位置？”，无需重新阅读所有文件。
