## 关键交互

### 钩子

| 钩子 | 触发时机 | 作用 |
|------|---------------|--------------|
| **SessionStart** | Claude Code 会话开始时 | 通知技能已就绪 |
| **PreToolUse** | 在写入/编辑/Bash操作前 | 读取 `task_plan.md` 以刷新目标 |
| **PostToolUse** | 在写入/编辑操作后 | 提醒更新阶段状态 |
| **Stop** | 当 Claude 尝试停止时 | 验证所有阶段是否完成 |

### 2次操作规则

每进行2次查看/浏览器/搜索操作后，必须更新 `findings.md`。

```
操作1：WebSearch → 记录结果
操作2：WebFetch → 必须立即更新 findings.md
操作3：读取文件 → 记录发现
操作4：Grep搜索 → 必须立即更新 findings.md
```

### 阶段完成

当一个阶段完成时：

1. 更新 `task_plan.md`：
   - 更改状态：`in_progress` → `complete`
   - 标记复选框：`[ ]` → `[x]`

2. 更新 `progress.md`：
   - 记录已执行的操作
   - 列出创建/修改的文件
   - 记录遇到的任何问题

### 错误处理

发生错误时：

1. 在 `task_plan.md` 中记录 → 错误记录表
2. 在 `progress.md` 中记录 → 带时间戳的错误日志
3. 记录解决方案
4. 切勿重复相同的失败操作
